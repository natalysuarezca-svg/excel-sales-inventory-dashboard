# Excel Sales, Inventory & Production Dashboard

## Project Overview

This project demonstrates an Excel-based data analysis and reporting workflow using sales, inventory, and production data.

The project includes data preparation, data cleaning, Pivot Tables, analysis, and an interactive dashboard designed to present key business information in a clear and organized format.

## Tools & Technologies

- Microsoft Excel
- Advanced Excel
- Pivot Tables
- Data Cleaning
- Data Validation
- Data Analysis
- Data Visualization
- Dashboard Design

## Project Workflow

The project follows these main steps:

1. Import and review the raw data.
2. Clean and organize the dataset.
3. Validate data for accuracy and consistency.
4. Create calculated fields and analysis.
5. Build Pivot Tables to summarize the information.
6. Develop an interactive Excel dashboard.
7. Present key sales, inventory, and production information through visualizations.

## Project Components

### Raw Data

The original dataset used as the starting point for the analysis.

### Data Cleaning

Data was reviewed and organized to improve consistency and usability for analysis.

### Pivot Tables

Pivot Tables were used to summarize and analyze the data from different perspectives.

### Dashboard

The final dashboard provides a visual summary of the analyzed information and helps users understand the main business metrics.
